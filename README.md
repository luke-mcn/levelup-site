# Level Up website

A one-page site showing off Level Up. Plain HTML and CSS: no build step, no dependencies.

## Files

- `index.html`: the whole page, styles included
- `assets/icon.svg`, `assets/favicon.svg`, `assets/apple-touch-icon.png`: the app icon
- `assets/og-image.png`: the preview image shown when the link is shared
- `assets/fonts/`: Chakra Petch, Space Grotesk and Inter (SIL Open Font License)

## Publishing with GitHub Pages

1. Put these files at the top level of a **public** GitHub repository.
2. In the repository: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, branch `main`, folder `/ (root)`, then **Save**.
3. After a minute or two the site is live at `https://<your-username>.github.io/<repo-name>/`.

Edit `index.html`, commit and push, and the site updates by itself.

The phone screens on the page are drawn in HTML with sample data, not screenshots of real accounts.
